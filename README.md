# نظام إدارة المخزون — صفحة موردو المخزون

صفحة ويب لإدارة أصناف موردي فرع واحد من المخزون: استيراد من إكسل، تعديل يدوي، تصدير، وطباعة مقسّمة حسب المورد.

التطبيق **يعمل بالكامل من المتصفح** (لا يوجد خادم أو قاعدة بيانات) — البيانات تُخزَّن محليًا في متصفحك عبر `localStorage`، وقراءة/كتابة ملفات الإكسل تتم بالكامل في المتصفح، ما يجعله جاهزًا للنشر مجانًا على **GitHub Pages**.

## التقنيات

React + Vite + Tailwind CSS (تصميم عربي RTL بالكامل) + مكتبة `xlsx` (SheetJS) لقراءة وتوليد ملفات إكسل داخل المتصفح.

## التشغيل محليًا

```bash
npm run install:all   # تثبيت الحزم
npm run dev            # تشغيل خادم التطوير
```

افتح المتصفح على الرابط الذي يظهر (عادة `http://localhost:5173`).

## النشر على GitHub Pages

تم إضافة وركفلو جاهز في `.github/workflows/deploy-pages.yml` يبني التطبيق وينشره تلقائيًا. خطوة واحدة فقط مطلوبة منك (مرة واحدة):

1. اذهب إلى **Settings → Pages** في المستودع على GitHub.
2. تحت **Source** اختر **GitHub Actions**.
3. بعد أي دفع (push) إلى فرع `main` سيُبنى الموقع تلقائيًا وينشر على:
   `https://newsaleh.github.io/SlowItems/`

   يمكنك أيضًا تشغيل الوركفلو يدويًا من تبويب **Actions** على أي فرع عبر "Run workflow" قبل الدمج إلى `main`.

> ملاحظة: لأن التخزين محلي (`localStorage`)، البيانات المستوردة/المعدَّلة تبقى في متصفح الجهاز الذي استُخدم فيه فقط، ولا تُشارك تلقائيًا بين أجهزة مختلفة.

## آلية عمل الصفحة

- **الاستيراد**: رفع ملف إكسل يحل محل بيانات الفرع الحالية بالكامل في هذا المتصفح (كل فرع يُرفع له ملفه الخاص بشكل منفصل، فلا حاجة لاختيار فرع عند الاستيراد). الأعمدة المتوقعة في الملف:
  - رمز المورد → **المورد**
  - اسم المورد → **الاسم**
  - اسم مجموعة المخزون → **البيان**
  - الموديل → **موديل**
  - الرصيد الحالي → **الرصيد**
  - السعر الحالي → **السعر**
- **التعديل**: إضافة/تعديل/حذف أي صنف مباشرة من الجدول.
- **الترتيب** (مطبّق في العرض والتصدير والطباعة): حسب المورد تصاعديًا، ثم داخل كل مورد حسب **البيان** تنازليًا، ثم حسب **الرصيد** تصاعديًا.
  > ملاحظة: طلب المستخدم كان الترتيب حسب "الصنف" — بما أن الحقول المستخرجة لا تحتوي عمودًا بهذا الاسم بالضبط، تم اعتماد عمود **البيان** (اسم مجموعة المخزون) باعتباره الأقرب لمعنى "الصنف". يمكن تغييره بسهولة في `client/src/sort.js` إذا كان المقصود عمودًا آخر.
- **التصدير**: ملف إكسل يُنزَّل مباشرة من المتصفح، يحتوي جدولًا منفصلاً لكل مورد يفصل بينها سطر فارغ، ليسهل قص الورقة عند الطباعة بحيث يكون كل مورد في ورقة مستقلة.
- **الطباعة**: نافذة تطلب اسم الفرع والفترة (من/إلى) قبل الطباعة، وتُستخدم هذه القيم في رأس الصفحة المطبوعة فقط (لا يوجد عمود تاريخ في البيانات نفسها).

## هيكل المشروع

```
client/                 تطبيق React (الواجهة والمنطق بالكامل)
  src/storage.js         طبقة التخزين المحلي (localStorage)
  src/excel.js            قراءة/توليد ملفات إكسل داخل المتصفح
  src/api.js               واجهة موحّدة تُستخدم من صفحات الواجهة
  src/pages/               صفحات التطبيق
  src/components/          مكوّنات الواجهة (نماذج، طباعة، تخطيط)
.github/workflows/       أتمتة نشر GitHub Pages
```
